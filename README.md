# HR_Attrition_Dashboard

An HR analytics dashboard developed using Microsoft Excel to analyze employee attrition from different dimensions.

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* DAX
* Slicers
* Data Analysis
* Dashboard Design

## Key Analysis

* Employee attrition by department
* Attrition by job role
* Attrition by gender
* Attrition by age
* Attrition by salary
* Attrition by education
* Attrition by years at company
* Attrition by job satisfaction

## Project Work

* Cleaned and transformed raw HR data
* Created PivotTables and PivotCharts
* Built an interactive Excel dashboard
* Added slicers, filters, and KPI cards
* Analyzed employee attrition from different dimensions
